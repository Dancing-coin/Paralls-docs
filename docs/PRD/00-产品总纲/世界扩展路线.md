<a id="continuity-roadmap"></a>
## 1. 扩展同一个世界

五阶段是空间范围、组织层级、内容、配置与容量的扩展，不是五个菜单模式或五套互不相容的游戏。骑战、步战、指挥、治理、后勤、贸易、细作、人口生活和政治共用同一时间线、存档与权威事实。角色、关系、资产、伤病、声望、组织和已发生战争后果应持续承接。

玩家始终具身存在；近场/远场和工作层改变关注精度，不重置身份和世界。正式时间、权限、信息规则分别见[连续世界、时间与暂停](../01-全局规则/连续世界、时间与暂停.md)、[身份与操作入口](../01-全局规则/玩家身份、权限与操作入口.md)、[信息边界](../01-全局规则/信息可见性与认知边界.md)。

<a id="five-stages"></a>
## 2. 五阶段方向

| 阶段 | 世界范围 | 核心体验 | 内容与容量扩展方向 |
|---|---|---|---|
| 一 | 一座县城、周边村落、野战区、攻方营地和粮道 | 活的县城战争社会；当前统一交付为召陵县县城守城 Demo | 县城攻守、出城野战、坚壁清野、断粮、细作、投毒、伤病、军心/士气、人口/职业、资源/后勤与城池持续运行。能力目录不等于所有情景都纳入首个可玩版本 |
| 二 | 一个郡内多县、村落、商路与关隘 | 打下城池后守住、经营并维持生产与通商 | 占领治理、县令任命、税粮、商路、运输网络与经济战 |
| 三 | 多郡、多势力、多战线 | 多郡持续战争与政治经营 | 联盟、背叛、投降、郡守体系、地方派系、跨郡兵源和粮道 |
| 四 | 州域郡县、州府、关隘与军团 | 战略纵深与州域政治整合 | 州级税粮、军团、州府、战略仓储和合法性 |
| 五 | 东汉十三州及主要势力 | 争霸、割据、统一或重建秩序 | 州际战争、全国人口/资源网络、势力联盟、历史分岔与长期秩序 |

这是目标路线，不是承诺全部内容已经制作。各阶段制作顺序、验收和基础设施建设只在执行路线维护，避免另起竞争排期。

<a id="county-world"></a>
## 3. 第一阶段的完整世界方向与当前交付

一座县城应是依靠人口、生产、贸易、命令与关系维持的战争社会，不只是战斗地图。玩家可骑马或步战，也可通过将领、军需官、工匠、村民、商人与细作影响战局；个人战斗不能取代组织、后勤与政治，组织行动也不能剥离个人位置、信息与风险。

历史大纲提出的连续地理候选包括：中小型县城；城门、城墙、街区、粮仓、水井、工坊、医舍、民居与指挥所；周边两或三个村落；农田、林地、道路、桥梁或浅河；攻方营地、器械工地、粮站；一条可护送、袭击或切断的主粮道；伏击、追击、突围与援军接战的野战区。**这是原设计候选清单，具体尺寸、村落数与当前制作范围以 Demo 场景及执行路线为准。**

连续县城的长线循环为：

日常治理与关系 → 侦察敌情、商路与粮道 → 坚壁清野、征召、训练、修城、配给 → 攻方建立营地、运输线与器械工地 → 出城野战、护送、伏击或闭城 → 围城、断粮、缺水、疾病、投毒、细作与城墙攻防 → 突围、援军、投降、破城或撤围 → 伤亡、迁移、库存、设施、关系与政治后果 → 战后恢复与下一轮冲突。

此处描述完整县城社会的目标，不把攻方可玩、完整战后经营、全部灾害或所有攻城方式追加为当前 Demo 门槛。已确认的当前专门化是：玩家为该县最高统治者，军政一体；固定守城方视角；支持跨多日保存、暂停与恢复；核心围城窗口约 30 个世界日，真实分钟数由时间倍率和试玩校准。玩家死亡、投降与逃离的失败条件以当前 Demo 胜负配置为准；详细来源“失守后投降”与摘要措辞差异见[待决 D08](设计决策与待决问题.md#d08)。水攻、火攻、地道首版范围及战后继续经营/进入第二阶段仍待确认。

《骑将冲阵》取消独立开发与验收，但通用骑战、视角、传令、预案、阵型、士气和目标交互继续服务本阶段。旧三队、命令编号与短时长配置只见[历史档案](../../archive/PRD/骑将冲阵垂直切片（已取消独立开发）.md)。

## 4. 能力连续与技术引用

技术建设计划要求第一阶段建设完整 23 Owner 的基础能力，以召陵县内容与跨阶段 fixture 检验；后续阶段扩展内容、配置与容量，而不是到后续阶段才开始具备产权、经济或政治的基础权威。此项是**建设目标**，不是实现结论。唯一名单、领域边界和验收事实见[Owner 注册表](../../architecture/03-Owner领域/01-Owner注册表.md#owner-registry)，全量节奏与同步规则见[UE 本地提交与 Paralls 同步](../../architecture/05-运行时接入/01-UE本地提交与Paralls同步.md#ue-cadence-matrix)。

| 能力方向 | 第一阶段内容 | 随世界扩大后的内容方向 |
|---|---|---|
| UE–Paralls 接入 | 正式适配、获准本地执行、恢复与同步链 | 复用契约并验证规模，不另建世界真相 |
| CharacterAgent | 关键将领、军需、商人、村民与细作 | 县令/官吏/商队 → 郡守/派系/外交 → 州级官将 → 州牧/势力首领 |
| Population | 县城、村落与攻方营地 | 郡内多县网络 → 多郡迁移 → 州域聚合/展开 → 十三州人口和资源网络 |
| Siming | 粮荒、民怨、兵变、援军与围城态势的压力/机会候选 | 城际风险与经济战 → 多线政治催化 → 州域趋势 → 势力变化与历史分岔 |
| 领域权威 | 全量基础能力规划，以县城内容与 fixture 验证 | 贸易、占领、治理、多郡战争政治、州域和全国内容/容量 |

这些能力由技术架构规定事实所有权和运行边界；本路线不复制公共契约，也不把 Paralls 已有原语等同于完整经济战、人口生存、军队自治或全国战争已经实现。

## 5. 完整战役、角色路线与增长候选

原总案提出 196—198 年兖豫地区、约五座城池/坞堡的完整战役候选，以小范围势力互动验证长线系统。曹操方向强调屯田、强弩、朝廷名分；吕布强调突骑、陷阵、部曲不稳；袁术强调世族财力、杂兵基础与僭号风险。派系差异来自制度、资源、人才和关系，不能为每派复制独立兵种体系。这些是候选，不指定已经落入五阶段中的哪一阶段，也不覆盖召陵县当前交付。

默认完整游戏角色方向为原创代理人，可依附、服务、受任、背叛或取代历史势力；历史君主直接开局留后续模式评估。校尉/都尉 → 郡守/中郎将 → 州牧/将军 → 诸侯/霸府只是政治晋升的可能路径，由任命、军功、承认、领地、组织与事实控制形成，不是固定职业 XP 条。

前期可聚焦角色行动、直属组织、命令和基础战场目标，挑战在通信、位置、阵型/士气与个人暴露；中期增加预案编辑/版本、授权、继任、区域战役和资源网络，挑战多线、补给和情报时效；后期涉及派系、经济战、政治、继承、历史分岔与更大组织，挑战持续成本、领域约束与承接风险。前中后期是内容组织候选，奖励表、时长和开放顺序未定。

火药分支默认关闭，属于架空长线或特定后期剧本开关；不能因此要求当前 Demo 制作。季节规则见[连续世界时间](../01-全局规则/连续世界、时间与暂停.md#season-and-cadence)。

<a id="long-term-acceptance"></a>
## 6. 长期体验与终局边界

完整世界应验证：同存档中个人行动与组织行动相互承接；城内、村落、营地、道路、粮道与野战区连续；职业/兵种转换不丢失人物；战争受位置、地形、训练、装备、命令、后勤、生命、军心、士气和关系共同作用；供应、缺水、疾病、投毒、细作和商路变化形成可观察后果；资源从源头、运输、仓储、市场到消费端影响战争持续力；经济影响经身体、劳力、士气和组织解释，不能只有隐藏惩罚值。

关键角色决策可追溯到感知、记忆、意图与过滤；日常自治由职责、脚本与预案支撑。角色、司命与群体消费同一权威来源的公开/受限投影。跨域结果应可解释失败、部分成功、恢复与回放。战争结束后人口、设施、库存、关系、伤病和政治状态不重置。这些属于长线方向，当前正式完成条件以 Demo 和基础设施门为准。

个人行动没有单独“进入后开始”的目标；治理目标、局部战斗胜利、战役任务与战争收束都不等于整局通关。完整游戏具体主线目标、结局、死亡/组织瓦解/关键承认丧失是否终局，撤退、僵持、割据、拥立及历史分岔的判定，均待确认。长期设计考虑在合法继任与角色承接中继续，但承接损失、权限及可恢复项必须可见；不能推导为无条件重置或改变当前守城失败。
