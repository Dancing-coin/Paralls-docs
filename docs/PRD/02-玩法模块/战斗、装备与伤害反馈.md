## 1. 主动与被动战斗

战斗是具身行动在敌意条件下的升级，不是脱离持续世界的竞技场。玩家可以主动攻击或接近风险，也可能因感知到敌意、伏击、追捕或攻击被动进入接触。切换界面不能取消已经发生的危险；敌意可打断治理、会议、沙盘或其他工作层互动。

玩家即时移动、选敌、攻击、防守、保护和撤退，受地形、身体、装备、暴露、敌方响应与组织脱节约束。个人行为改变局部事实，不能独占部队胜负、战役结果或战争收束。攻击方向、格挡/闪避、接触距离、姿态承诺和受击反馈参考《荣耀战魂》的可读性；完整动作、具体判定与数值尚未定稿。

## 2. 接触、防护与身体后果

| 玩家可观察环节 | 条件与成本 | 结果与反馈 | 异常边界 |
|---|---|---|---|
| 攻击尝试、命中或格挡 | 目标、路径、接触方向与现场条件有效；动作和资源成本待定 | 区分尝试、命中、被阻、格挡、伤害评估 | 不以动画完成证明命中；无效目标或冲突需说明原因 |
| 装备防护与耐久 | 读取适用装备状态及固定版本的防护条件 | 说明防护、耐久损耗与破损，剩余伤害再进入身体 | 不由攻击方自行写对方装备损坏或跳过防护 |
| 伤害应用与伤势 | 承接已评估剩余伤害 | 伤势、身体功能、体力和能力限制持续影响行动 | 伤害评估与实际应用不能混为同一事实 |
| 流血等状态 | 依合法状态创建、周期和解除条件运行 | 显示效果创建、持续、减轻/解除及身体变化来源 | 效果和 Buff 不自行扣/加生命；暂停不额外推进 |
| 倒地、濒死、死亡或俘获 | 依据确认后的身体、生命及组织事实 | 明确失能、生命周期变化、后续控制与后果 | 动画或目标脚本不能直接判死/俘获；见[生存与传承](角色生存、成长与传承.md#failure-inheritance) |

同一语义节点需协同确认时，必须遵守[身体领域契约](../../architecture/03-Owner领域/02-领域Owner详细契约.md#body-domains)、[公共事件与回执](../../architecture/02-公共契约/02-Command事件与Receipt.md#command-event-receipt)及[本地提交](../../architecture/05-运行时接入/01-UE本地提交与Paralls同步.md#local-commit)。本页描述玩家结果，不设第二写入方，也不新增伤害 Owner。

## 3. 装备、器械与科技

骑将武器改变个人接触方式和风险，受角色能力与装备状态约束；个人冲击不能替代组织。军旗是归属、士气及目标道具；传令凭据证明来源或改善可达性，其复杂度与表现待定。军旗和器械目标规则由[战场目标](士气、阵型与战场目标.md#objectives)正式维护。

器械必须有控制者、操作人员、补给、损坏与完整/损坏/残骸表现。长期内容目录如下，目录不等于当前县城 Demo 配置或已实现清单：

| 类别 | 来源目录与范围 |
|---|---|
| 防御设施 | 拒马、鹿角、铁蒺藜、壕沟、土垒、栅栏、营寨、望楼、陷阱、绊马索 |
| 攻城器械 | 云梯、冲车、盾车/洞屋、井阑、投石车、弩炮、地道/火攻；大型攻城塔为后续方向 |
| 运输与工程载具 | 辎重车/粮车、盾车、武刚车/偏厢车、工程车/推车、浮桥/舟桥；战船后续 |
| 消耗和信号物 | 火油/火把、旗帜、鼓号、烟尘/信号、医药和担架 |

战车不另立独立兵种体系；武刚、偏厢先验证车阵、运输与反骑用途，不能把历史名词直接当成免费战斗加成。

<a id="technology-equipment"></a>
### 3.1 技术与换装方向

科技以兵器、甲胄、弓弩为核心，攻城、通信和后勤后续扩展；火药仅作为架空/后期开关，是否启用待阶段决定。投入包括铁、木、皮革、油、钱、工匠、方士/工程师、工坊和实战经验；仅火药路线增加硝石需求。生产与科技不是无成本属性膨胀：同时改变生产能力、成本、耐久、伤害/防护及训练门槛。

| 装备方向 | 原来源中的候选递进 |
|---|---|
| 长杆戟 | 木杆铁头 → 炒钢/百炼/精钢方向 |
| 环首刀 | 生铁 → 炒钢/百炼/精钢方向 |
| 札甲 | 皮甲 → 铁札/精铁/钢札方向 |
| 弓弩 | 单体 → 复合强弓、强弩及有限连弩方向 |

分支目录还包括矛、刀、剑的材料和结构，盾牌蒙皮与铁盾、弩机改进；攻城分支改进云梯、冲车、投石车和弩炮；通信后勤改进旌旗制度、鼓角训练、驿站、望楼和传令效率。架空火药目录保留火油、火箭、火门枪、突火枪、震天雷和早期臼炮，目录不构成当前 Demo 开放承诺。

工匠与知识可经俘虏、缴获、贸易、婚姻、学舍、投奔流动；保护机密、垄断与传播具有政治代价。可让老兵保留旧装备、新兵采用新预设、精锐优先换装；具体配方、换装条件和最终顺序仍待平衡，不承诺一次全部开放。生产成本、认证和运输见[资源模块](资源、生产、经济与运输.md#production)。

## 4. 反馈、平衡与待定

- 稳定区分接触方向、命中/被阻、阵型状态、士气区间、目标控制和关键指挥者状态；以动作、形状、图标、文字、声音和颜色组合表达。
- 承诺前展示合法可知成本、主要风险及可能结果类别，接触后给出命中、伤势、目标/队伍变化和因果来源。不得用未知攻击或隐藏随机造成无法学习的核心损失。
- 关键接触优先，镜头震动、暂停帧、音效可调，不能遮挡后续威胁、军旗、队形和命令结果。
- 检查单骑反复冲锋、单一构筑或英雄技能是否压过组织、地形、补给与协同。先改反馈、目标差异、通信提示、预案与接触风险，再调数值。

正式攻击/防守/闪避动作集、生命与体力、伤害防护公式、成长曲线、随机规则、确定性种子、失败保护和单位换算均待定；不得用本页候选方向伪装已完成平衡。观察需可重复记录局部接触、装备防护、身体伤势、阵型/士气和目标事实的先后关系。
