<a id="resource-network"></a>
## 1. 同一资源网络

盐、粮、铁、马料是同一资源网络的四个核心实例，可扩展皮革、木材、药材、油和钱。五阶段大纲的粮食、水、盐、药材、木材、石料、铁料、箭矢、马匹、驮畜、工具及现金/贸易物资保留为首批内容候选；是否全进当前 Demo 由阶段配置决定。

`源头/生产 → 提纯/加工 → 储存与产权 → 装载与运输 → 实际抵达 → 城镇市场/公仓 → 家庭、军队、工坊、官府配给与消费`

节点记录种类、质量、数量、预留、产权、事实控制、生产能力、成本、容量、时间、风险、市场可见度、价格、需求、现金流、替代品和情报可信度。资源还需区分容器、保管、储存条件、污染/损坏与当前位置；食物腐败、木料腐朽、铁料锈蚀、箭矢受潮不是同一种无条件衰减。变化模型必须匹配资源标签、容器、作用范围、生命周期与输入版本。

| 关系 | 必须独立回答的问题 |
|---|---|
| 产权 | 谁在法律或契约上拥有资源？ |
| 保管 | 谁实际看守库存？ |
| 事实控制 | 谁能决定生产、发运和发放？ |
| 军事占领 | 谁控制节点周围的武力和道路？ |
| 市场影响力 | 谁能改变报价、信用、交易意愿与信息？ |

占领城池不自动取得商贾仓库、盐场或运输队。授权、谈判、接管、查封、交换、保护或合法程序分别改变关系；强行抄没可能失败，物资可能转移、藏匿或移出控制范围。个人战利品/任务报酬/竞技所得与领地税赋/贸易/商路预算分账。钱、粮、盐、铁、马料、木、皮革、油与工匠共同约束组织经济。

<a id="production"></a>
## 2. 生产、设施与运输

生产区分设施、设备、工匠、原料、任务及成品认证。中央与分散工坊在装备、工艺、原料和许可有效时可组合生产线；开工条件、产量、质量和中断结果分别记录。原料与成品是库存事实，劳动与排班是岗位事实。

来源产能框架：`配方基础产能 × 设备状态 × 工匠技能 × 原料质量 × 可用劳力 × 工序时间 × 安全/中断因素`。该式是待实现的因果要求，不是已经校准的数值公式。预留、取消、停工、认证和回放必须能识别重复与冲突；缺料、失去工匠、场所失控或安全风险不能静默产出。

运输须经过预留、承运人、路线、阶段位置、护送、阻塞/改道、截获、损失和入库回执。玩家堵路、敌军拦截或路径失效后，明确等待、改道、被截、损失或放弃；不以任务计时结束把货物瞬移入库。拆屋、拆家具设施、回收农具可以提供材料，但会损害居住、防御、劳动或其他生产能力，不能当作无代价新资源源头。

资源事实分别由[资源领域](../../architecture/03-Owner领域/02-领域Owner详细契约.md#resource-domains)校验并提交；需求、Agent、公式调用方或表现不得直接写库存、付款、产权、生产成功或认证。完整供给及伤病后果见[补给流程](../03-跨模块流程/补给、消耗与伤病救治.md#supply-flow)。

<a id="market-actions"></a>
## 3. 市场、预算与经济战

市场由本地可交易库存、有效需求、替代品、运输时长和风险、信用、管控政策及参与者掌握的信息形成。预留、藏匿、封锁或无法运达的库存不等于有效供应；玩家只能取得自身渠道的报价、成交和报告，并看到时间戳与可信度。投放可压价，但瓶颈、拒售、囤积、谣言和政策反应会改变成交量。

行动目录保留囤积、诱导囤积、反向放货、公仓平抑、限量配给、保护商路、截断运输、收购关键仓库、盐价管控、定向赈济、公开征用和秘密破坏。以现货库存、现金流及信息差实现效果，不引入现代期货、金融杠杆或抽象“做空”按钮。

| 经济战方向 | 目标与代价 |
|---|---|
| 军用断供 | 优先削弱敌军和军需，尽量保留平民市场 |
| 城市压迫 | 同时影响居民、劳力、军队；合法性、声望、叛乱及报复风险更高 |
| 市场夺权 | 争夺盐场、粮仓、商道、运输户与报价权，争取利润和政治控制 |
| 稳定战 | 公仓平抑、定向发放、保护商人、恢复运输，形成新占领地事实统治 |

选择政策必须指明目标范围；减少供应不直接等于全城混乱。后果经供应、价格、身体、劳力、组织服从和角色行动逐层结算。默认界面展示关键库存、现金流、军需天数、风险及异常市场信号；详细视图展示完整账目、报价、仓库、运输批次、债务、合同、税费和生产队列。代理受政策、权限、预算、组织承诺与事实约束；关键政策变化、越权请求、现金流危机及重大损失才请求玩家决策。

<a id="salt-merchant-case"></a>
## 4. 复合案例：新占领城的盐商博弈

商贾大族与旧势力结盟并运走盐；玩家公开抄没因仓库不在控制范围而失败，干扰市场还会伤害声望、市场信任及中立利益。

1. 在条件满足后解锁卤盐矿提纯，在附近秘密生产。
2. 保护产地和小规模运输并保密，使商贾可能误判储备不足。
3. 第一天投放 **1000 斤**、第二天 **600 斤**、第三天 **200 斤**，观察报价、收购及现金流。这些是原案例示意量，不是 Demo 固定配额或平衡结论。
4. 诱导对方高价囤盐，观察其现金流和仓储风险是否进入脆弱区。
5. 试探放货确认仍在接盘，再经公仓和市场按市价集中供给，使囤盐贬值。
6. 结合细作、查路、护运和定向破坏削弱库存及运输。
7. 对合格军户、重体力家庭、贫困户和关键劳力定向免费发盐，恢复劳动与秩序。
8. 将结果转化为市场信任、居民服从、运输合作及事实统治，而非仅显示金钱收益。

玩家只能依据产量、报价、成交、传闻、商人情报和多日试探推断对手；误判会耗尽自有库存、损害信用、刺激替代市场或遭反制。范仲淹式“收粮稳定市场、高价吸收供给、公仓调价”只作为原案的市场事件模板类比；每次结果仍由库存、现金、运输及人物行为结算，不将类比作为历史事实结论。

<a id="technology-economy"></a>
## 5. 技术流动、反馈与待定

技术是能力解锁及组织条件；资源、工匠、地域、政治关系、实战经验、缴获逆向、俘虏、贸易、婚姻、学舍和投奔影响流动。保护机密、垄断生产或主动传播可能换取盟友，也可能帮助潜在敌人。[装备与六系技术](战斗、装备与伤害反馈.md#technology-equipment)维护唯一目录；提升须可在战场、生产速度、维护成本、通信可靠性或市场竞争中感知。

正式资源目录、计量单位、需求/消耗周期、产能和配方、价格形成、信用/债务、税费、损耗、库存容量、运输成本风险、科技解锁与代理阈值待定。核查时应能追溯一次生产、预留、装载、运输、入库、消费及后果，包含拒绝、中断、损失和重复提交，不用隐藏全局惩罚替代链条。
