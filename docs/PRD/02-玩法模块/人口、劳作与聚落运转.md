<a id="population-work"></a>
## 1. 人口不是可替换数字

兵种与工种是角色当前职业，不是固定种族或永久类别。社会身份、技能、家庭、关系、伤病、记忆和经历随角色持续存在；征发、迁移、训练、战斗和返乡不能生成互不相干的新角色。

人口承担生产、运输、纳粮、修工事、募兵、城防与家庭生活；供给、疲劳、疾病、伤势及待遇影响可用劳动和服役意愿。个人意愿/恐惧/信任/服役态度、队伍军心与战斗士气、城市民心/治安/生产力分别表示，不能用同一总值覆盖。正式身体与社会后果见[生存模块](角色生存、成长与传承.md#body-social-consequences)。

| 辅兵及民间岗位候选 | 主要职责 |
|---|---|
| 搬运与运输 | 装卸、承运、接收及道路协作 |
| 木工 | 木构修缮、器具与生产工序 |
| 土石工 | 土石工程、城防与修复 |
| 炊事与供水 | 备餐、供水及发放协作 |
| 医护与担架 | 转运伤员、排队救治及照护 |
| 军械维护 | 维修、保养和装备状态检查 |
| 畜养与车马照料 | 马匹、驮畜、车辆和饲料照护 |
| 斥候与信使 | 观察、递送、路径和风险反馈 |
| 商人及行脚运输 | 贸易、信用、商道与运力 |
| 细作及情报中间人 | 接触、证据和有限信息流通 |

以上保留大纲“第一阶段至少”十类工种的原始目录，但本次不把目录自动提升为县城 Demo 全量验收。七类战斗职业及长期二十兵种目录只在[军制模块](军制、指挥与自主行动.md#troop-catalog)维护。

<a id="role-transitions"></a>
## 2. 转岗、征发与拒绝

来源示例完整保留：`村民 → 征召民夫 → 搬运工 → 接受长枪训练 → 守城枪兵 → 受伤 → 医舍休养 → 返回木工或家庭岗位`。角色身份和关系连续，训练、装备、伤势与经历不能在转岗时重置。

职业变更需要时间、装备、技能、岗位交接和组织许可。疲劳、伤病、家庭责任、待遇、权限或恐惧可导致拒绝、延迟、要求修改或替代安排；合法义务不等于自动服从。显示原因、负责岗位、影响任务、现有能力和后续安排，组织处罚、信任及未来授权另行结算。

排班与生产需共享实际可用劳力；同一人不能同时完成互斥岗位。调走守军去修城会影响防御，征用运输户会影响家庭与商路；训练改善能力也消耗可用工时。具体班次、人口容量、工资/徭役和拒绝阈值待定。

<a id="settlement-capabilities"></a>
## 3. 聚落在战时持续运转

城内行动目录保留坚壁清野、粮水转移、牲畜收容、村落撤离；征召民夫、改派工种、训练新兵、轮休；私藏粮食、黑市、秘密运输、配给冲突；细作接触、收买、伪装、假消息和破坏供应；粮水投毒、污染发现、隔离、救治和追查；俘虏收押、招降、交换和编入组织；民众暴动、豪强倒戈、商人转向、守军哗变；将领失能、继任、权限重交与重新规划。

城外村民迁移、护送、征发和难民流动与城内岗位、资源、控制关系相连。这些是共享单位、地形、资源、命令、关系及权威结算的能力目录，不为每项建立独立小游戏。治理设施和政策见[治理模块](治理、政治与领土控制.md#governance)，库存与产能见[资源模块](资源、生产、经济与运输.md#production)，远场模拟及激活边界见[司命与角色智能体](司命与角色智能体体验.md#population-boundary)。

反馈应明确当前职业、岗位能力、待办/中断、调派原因、疲劳伤病、供给、训练与家属影响；组织概览与个人隐私信息分别按渠道可见。验证须观察转岗前后身份与伤势保留，以及一次劳力冲突/拒绝/接替的可追溯后果，不能只核对人数总计。
