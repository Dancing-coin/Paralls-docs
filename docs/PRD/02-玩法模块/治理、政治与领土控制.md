## 1. 影响力与统治力

影响力是有方向、对象、领域、辖区与时间的关系：`Influence(subject, target_group, domain, jurisdiction, time)`。来源包括合法性、信任与互惠、利益依赖、能力声誉、信息接入、组织覆盖、持续时间和强制力；军中声望不自动变成商人折价或全域政治承认。

行动至少区分三层：权限是否合法；对象是否因影响力响应；对应领域是否实际形成事实。答应、命令合法与事情完成互不等价。

统治力是通过组织、代理制度和执行机制稳定下来的影响力。形成条件包括持续承认、资源组织、辖区持续控制、合法性或事实承认及代理执行；不是单项声望达线即占领成功。状态保留未形成、形成中、生效、争议、崩解；进入与退出采用有滞后性的持续条件，按辖区与领域分别判断。短暂失仓不瞬间崩解，但税粮、军事、秩序及承认持续失效会降级。具体阈值和持续窗口未定。

盐商、仓吏、运输户、军队、居民、工匠、世族和官员是可有不同利益与响应的群体，不能被单一城市服从值代替。

<a id="governance"></a>
## 2. 内政、组织与委派

领地经营覆盖郡县城池、坞堡、屯田、武库、市肆、学舍/察举、城墙及兵营。玩家查看资源和政治态势，设政策、预算、责任人和检查条件，任命与授权下属持续办理，也可亲自接管具体事项。治理目标、岗位分工、预算、结果核查和反馈组成完整闭环；政策影响税赋、供给、地方秩序、军需与关系。

启动治理要求对相应辖域、资源、机构或交易具有有效身份/权限，并拥有可获得的信息，具体身份门槛待定。流程为读取已知状态→提交目标、预算与执行条件→责任人及相应领域校验权限/资源→按生产、运输、交易、消费周期持续执行→承认结果并经汇报进入玩家认知。

治理反馈区分目标已提出、已受理、执行中、延误、部分完成、完成、拒绝；这是策划执行信息，正式状态机待技术合同确认。执行占用时间、库存/现金、劳力与组织能力，收益体现为供给、生产、合作和统治稳定。核查必须显示执行者、已知源头—仓储—运输—消费链、计划与实际差异、异常来源及可介入窗口。权限变化、资源短缺、运输受阻或代理拒绝可造成延误或部分成果；军需挤占治理余量，战争损失影响后续生产与承认。切换界面不撤销已发生消费，也不取消责任或代理行动。

委派不是硬锁，玩家可推翻决定，但信任、组织服从、损失及政治关系会变化。任命忠诚官员不等于自动解决盐价，其权限、库存、人员、能力与自身利益仍受约束。资源重分配、军事征发和地方治理竞争同一有限条件，不能免费全选。

任命/授权依次明确责任人与范围，校验资格、承认和资源，再由代理依职责、能力、关系和自身意图行动，经合法渠道汇报后调整组织。维护合作、监督执行和争取承认占用时间、资源与关系；委派节省操作但不保证忠诚、精确或成功，责任、资源、关系、承认和权限变化都须有来源。具体撤换及政治继任规则待定，即时指挥交接见[继任流程](../03-跨模块流程/命令传递、执行与指挥权轮替.md#succession-flow)。

组织关系可通过任命、授权、分封、联姻、拉拢、分权、制衡、质子、征辟和保护有限设计；性格、利益、军功、恐惧、记忆、亲缘与组织状态决定实际冲突。平时展示部曲忠诚、世族支持、军队服从、地方秩序、市场信任、军粮安全及合法性等组织指标，个人意图须由[社交情报](社交、关系与情报.md#information-knowledge)发现。

## 3. 占领、统治与战争结果

新占领地经历 `军事占领 → 名义统治 → 事实统治 → 稳定统治`。事实统治要求税粮、治安、司法、运输、市场和关键人物持续配合；统治力激活是其组织化表现。军事控制、产权、保管、资源控制和市场影响独立，详见[资源关系](资源、生产、经济与运输.md#resource-network)。

控制节点、军旗、将领、器械、道路或城门是局部事实；占城、投降、撤退、收容、损毁、政治承认与长期收益须经过相关领域结算，不靠镜头、面板或一次个人击杀直接盖章。战役与战后流程在[跨模块流程](../03-跨模块流程/战役推进与战后结果.md#war-results)维护。

玩家必须权衡前线与后方、直接控制与代理效率、即时军需与长期生产、强制征用与信任、名分与自主、集中与分权。治理成功、战斗胜利和角色成长相互影响但不互相替代；完整游戏目标、通关、失败与结局结构未定。

<a id="diplomacy"></a>
## 4. 外交、合法性与待定

外交行动包括表奏朝廷、盟誓、质子、联姻、征辟、世族交涉、赎俘、交换和承认；公开承诺、私下意图、履约能力及对方实际认知必须分开。汉室合法性、世族支持和部曲忠诚互相牵制：朝廷名分带来官职秩序但限制自主；依赖世族带来钱粮人才但让渡地方权力；扩大直属部曲增强个人控制也增加军饷和继承风险。

反馈交代政策/命令来源、作用辖区、受影响群体、代理、预算、执行进度、拒绝/损失及可知后果；报告不能暴露未获取的私人意图。正式政治承认、影响计算、统治阈值、关系变化、继承权力、组织制度及外交履约参数仍待定。技术事实来源见[领域 Owner](../../architecture/03-Owner领域/01-Owner注册表.md#owner-registry)，本页不另建权威结算系统。
