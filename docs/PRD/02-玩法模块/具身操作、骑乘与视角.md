## 1. 玩家行为与条件

玩家始终以一个有身体、位置和感知范围的人存在；移动、骑乘、观察、交互、履职、社交和战斗共享同一角色。工作层的全局激活和时间规则由总纲维护，本模块只维护具身操作。镜头和面板不是另一个角色，也不授予远方控制权。

| 行为 | 条件与输入 | 成本与结果 | 反馈与失败 |
|---|---|---|---|
| 移动、观察 | WASD 移动、鼠标控制朝向；其他绑定待定；受地形、碰撞、身体和现场条件限制 | 花费时间并改变位置、速度、暴露、观察范围与通信可达性 | 动作、方向、速度、距离、可见目标和危险提示；阻挡、绕行、拦截、脱离必须可辨 |
| 骑乘、接近与冲锋 | 拥有可骑乘单位，目标有效且存在接触路径；骑乘/冲锋键位待定 | 形成局部接触压力、目标推进或救援窗口，同时承担受阻、失序、受伤、坐骑状态和通信机会成本 | 显示路径、速度、方向、接触来源、命中/受阻、目标及队伍状态；不能无限无成本反复冲锋 |
| 切换观察视角 | 第一人称、第三人称、俯视关注；按键、可用条件与控制细则待定 | 改变观察呈现和信息组织；不复制、传送玩家，不暂停或改写世界 | 镜头过渡、视角标识、可见信息边界；不得因此暴露未获知情报 |
| 亲自介入或保持指挥位置 | 根据已知敌我、目标、命令和身体状态判断 | 亲战改变局部接触但增加暴露、拉远传令距离；留位更易观察传令但让出个人机会 | 行动前后都提供风险线索；亲战不能稳定替代组织协同、后勤和通信 |
| 休整与处理身体问题 | 有安全地点、资源或照护条件；具体门槛待定 | 消耗世界时间与资源，身体后果见[角色生存](角色生存、成长与传承.md#survival-body) | 疲劳、伤势、时间及风险变化；世界其他事务继续 |

<a id="encounter-actions"></a>
## 2. 接触中的行动节奏

遭遇采用“发现 → 选择 → 承诺 → 接触 → 重组/撤退”的可读节奏。玩家先辨认威胁、目标和路线，选择接近、攻击、防守、保护或撤退；承诺后承担位置与身体后果，接触后依据阵型、士气、目标和新信息重新判断。

冲锋撞击完整阵型存在受阻、失序与受伤风险；地形、敌方威胁和不利传令距离会增加风险或信息损失。正常接近只更新位置、可达性和接触候选；冲锋也只形成需要合法判定的局部接触，不能直接宣布队伍溃败或目标完成。

| 情况 | 必须承接的结果 |
|---|---|
| 可观察目标正常接近 | 更新距离、方向、危险、命令可达性与接触候选 |
| 有效路径上的冲锋接触 | 产生接触风险和局部影响，反馈阵型/士气/目标压力及来源 |
| 地形、威胁或命令距离不利 | 可选择继续、撤退、改令，承担明确风险和暴露后果 |
| 碰撞、目标消失、超出范围、玩家失能 | 中止、调整或拒绝须留原因；不得静默成功 |

<a id="movement-feedback"></a>
## 3. 操作反馈与界面

- 输入响应与持久结果分开：动作播放和碰撞表现不等于位置、伤害或目标事实已确认。
- 关键接触优先于装饰效果；方向、是否命中/被阻、附近危险和可撤退/求援路径应可辨认。
- 镜头震动、暂停帧和音效强度可控，不能遮挡下一条威胁或命令结果；状态不能仅靠颜色表达。
- 个人行动界面显示位置、身体、身份、附近人物、交互对象及可获知信息；战斗 HUD 补充视角、当前危险、附近目标、队伍可知状态和命令状态。
- 可调整键位重映射、鼠标灵敏度、镜头距离、视角偏好和颜色辅助；具体选项及默认值待定。

## 4. 关联规则与验证

攻击、防护、伤害见[战斗模块](战斗、装备与伤害反馈.md#combat-contact)；位置改变通信条件后的过程见[命令流程](../03-跨模块流程/命令传递、执行与指挥权轮替.md#command-lifecycle)；目标和队伍反馈见[士气阵型模块](士气、阵型与战场目标.md#battlefield-state)。

技术接合只引用[UE 本地提交](../../architecture/05-运行时接入/01-UE本地提交与Paralls同步.md#local-commit)、[领域契约](../../architecture/03-Owner领域/02-领域Owner详细契约.md#military-domain)及[受限投影](../../architecture/02-公共契约/03-受限查询与投影.md#restricted-projections)：局部执行须区分候选、表现和确认事实；不逐帧把 Actor 坐标当事件存档。

验证观察：第一/第三/俯视改变呈现但不改变角色和时间；位置确实改变接触、暴露和传令条件；关键损失有前后线索和可追溯来源；亲战与留位各有适用情境。具体动作集、移动/骑乘数值、碰撞和失能切换条件、视角限制、手柄支持仍待定。本页不是独立“骑将冲阵”开发或验收目标。
