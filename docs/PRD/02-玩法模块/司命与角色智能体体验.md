## 1. 历史压力与司命体验

历史事件是有条件的压力点，有默认倾向，但参与者、时间、地点、规模、结果及是否发生可由玩家情报、军令、外交、经济战和亲战改变。若玩家长期未产生足够影响，世界按已登记历史倾向推进；主线、压力点及具体分岔范围仍待内容设计。

司命（Siming）负责全局态势、高层催化、公平审计、候选、政策与可行性。它可提供 `impulse`、`opportunity`、`fact_reveal` 或压力变化，推动历史趋势；不能直接宣布城池易手、人物死亡、库存变化、战争胜负或角色已决定行动。玩家应看到有来源的机会、压力与揭示，不看到无因果的幕后扣分。

司命提出压力/机会/候选，角色与群体在授权范围内承接，对应领域校验权限、版本、成本及因果后提交事实和回执。“官府有盐、普通人无盐”的不公先经观察、传闻、解释与角色候选行动，再可能成为抗议、举报、拒运、哄抢、投靠、隐忍或敲诈；不能直接写“居民忠诚下降 20”。

<a id="agent-activation"></a>
## 2. 角色日常与复杂决策

地方官、军队指挥官、军需官、部曲头目与关键商贾可激活为角色智能体；日常仍优先使用职责脚本、军制预案及规则程序。脚本未覆盖、利益冲突、谈判、继任、改投、抗命、重大危机和长期挂机决策才取得 `activation lock`，进入完整 CharacterAgent。

角色应从自身感知、记忆、身份、关系、身体、资源、权限和利益形成可执行候选。感知、理解、规划与执行意图不等于事实；角色可能拒绝、误判、延迟或自保，且玩家只经合法渠道获知。复杂角色智能不构成全知、无限资源或自动成功。

细作 L1–L4 与三重过滤器的玩法要求见[社交情报](社交、关系与情报.md#espionage)。Agent 提出的交易、关系、命令、身体或组织变化须交相应领域确认；不能直接写 morale、库存、产权、政治承认或世界结果。个人恐惧、意愿与队伍军心/战斗士气保持独立。

<a id="population-boundary"></a>
## 3. 群体模拟与唯一推进者

远场居民、运输户、普通士兵由 PopulationPlanner 使用 B0/B1 低成本推进，输出 `presentation_seed`、`activation_candidate` 或 `owner_bound_intent`。表现种子不等于库存、价格、关系、组织或身体事实；后者须取得对应领域回执。

同一角色在同一窗口只有一个推进者，不能 Population 与 CharacterAgent 双写。近远场切换保留身份、岗位、伤势、关系、预案、资源与既有事实，不生成第二套历史；切换失败、版本冲突、暂停及恢复须可追溯。实现契约只在[Agent/群体接入](../../architecture/05-运行时接入/02-Agent群体与动画接入.md#agent-population)、[多精度与交接](../../architecture/02-公共契约/04-多精度与Handoff.md#handoff)维护。

## 4. 反馈、验证与待定

世界应在玩家离场、切换关注层或失去通信后继续按合法职责和预案推进；不为保证戏剧效果直接生成胜负。玩家可通过人物表现、事件、战报及组织概览理解动机与后果，但私人思考和未知事实不默认公开。完整世界与暂停统一遵守[连续世界规则](../01-全局规则/连续世界、时间与暂停.md#active-pause)。

激活名单、触发阈值、优先级、每窗口预算、远场精度、记忆与报告频率、历史倾向登记、司命公平审计标准和实际 Paralls 版本仍待定。验证应分辨候选、接纳、领域提交、玩家获知四步，含拒绝、冲突、交接与无网络路径；本次文档整理不证明已接入或已通过运行测试。
