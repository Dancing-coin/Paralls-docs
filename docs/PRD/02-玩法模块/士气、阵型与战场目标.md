## 1. 队伍状态与作用

队伍至少有士气、疲劳、训练、补给、阵型、指挥状态、军旗状态和撤退意愿。玩家通过位置、冲锋、命令、护卫、目标选择和资源安排间接改变状态，不能拖动隐藏数值。输入包括已经确认的接触方向、伤亡、侧后方威胁、军旗、补给、指挥、疲劳、地形、敌压、战果、命令与组织关系。

这些事实形成状态变化，再触发预案和行为；良好状态提高执行、接敌与目标争夺能力，受压状态改变坚持、重规划、撤退或重整。成本由位置、时间、人员、补给和组织信用承担。多个事实同时到达、未知信息或状态冲突按事件时间及版本处理并留证，不用单一隐藏“混乱值”代替因果。

个体意愿、队伍军心、战斗士气、城内民心须分开。相同士气值不能强迫所有角色作同一判断；个人恐惧、解释与自主选择由角色产生，军心和民心也不能互换。角色 Agent 可提出 `rally`、`withdraw`、`protect_standard`，不能直接写士气、阵型或最终战果。近场压力应及时影响行动，不逐次等待 Agent/后端推理。

## 2. 状态词与候选参数

| 来源表述 | 保留规则与待决范围 |
|---|---|
| 玩法案阵型词 | 保持、压缩、松散、重组、溃散 |
| 总案阵型离散候选 | `formed / compressed / disrupted / flanked / rear_threatened / routing` |
| 玩法案士气词 | 稳定、受压、动摇、崩溃、恢复 |
| 总案士气候选 | 0–100 连续值映射 `steady / shaken / wavering / routing`；75/45/20 是旧骑战切片参考阈值 |

两套词表的最终映射、是否保留某些侧后方独立状态、恢复路径和阈值仍待评审；不得默默合并成已定状态机。75/45/20 仅保留候选来源，**不作为当前县城 Demo 验收或完整游戏最终平衡数值**。切换必须可读并有稳定停留，不因单帧噪声反复跳变。

<a id="objectives"></a>
## 3. 战场目标与开放行动

目标按具体战役配置，具有归属、状态、压力和有效性。可为军旗、敌方将领、主战队、攻城器械，也可支持夺旗、斩将、护送、抢粮、破坏器械、掩护撤退、抓捕、拖延与脱离接触；多目标争夺、目标失效和攻城目标树属于完整游戏方向。军旗是易读战场锚点，不是所有战争的唯一胜利条件；旧切片“军旗主目标”不能迁为当前县城唯一胜负规则。

| 行为/事件 | 条件、成本和结果 | 反馈/例外 |
|---|---|---|
| 接近、侦察、攻击、护卫、发令、撤退 | 目标有效，位置/权限/资源允许；占用队伍、时间与暴露，争取控制、破坏或撤退窗口 | 轮廓、归属标记、状态条、旗帜/器械表现、队伍任务与来源 |
| 改变目标压力或状态 | 玩家或队伍形成合法局部事实，再确认控制/破坏/失守/撤退 | 状态可包括未接触、可争夺、受压、控制、失守、破坏、撤退、失效 |
| 目标被摧毁、离场或情报过期 | 所有相关队伍重新评估目标及预案 | 显示失效原因和重规划，不静默结束 |
| 完全脱离接触且一方无法/不愿继续争夺 | 可收束该次战斗，保留损失与后续局势 | 局部收束不等于战役、战争或整局自动获胜 |

争夺收益可为战场优势、士气变化、撤退窗口及后续授权/声望，不只即时加减分。玩家拒绝或改写上级目标时，目标、军纪、信任、声望、关系和后续授权各自承接，见[战役结果流程](../03-跨模块流程/战役推进与战后结果.md#war-results)。

<a id="enemy-roles"></a>
## 4. 对手职能与识别

| 职能 | 行为与应对 | 识别方式 |
|---|---|---|
| 主战队 | 保持/推进阵线、接敌、响应命令；可利用侧翼、目标转移、士气压力和协同，具体弱点待定 | 队旗、编队、站位、行动预警 |
| 军旗队 | 保护旗帜、维持组织；可分割、突击或命令协同 | 明确旗帜轮廓与归属 |
| 敌方指挥头目 | 发令、重规划、撤退、继任；可切中继、迫暴露、改目标压力 | 人物轮廓、命令反馈、护卫关系 |
| 冲车/器械队 | 沿路线施压、推进并保护器械；可侧袭、破坏或引导队伍处理 | 轮廓、路线、状态、损坏与破坏反馈 |
| 骑战单位 | 冲锋、拦截、追击、护目标；可用队形、地形、集火应对 | 速度、方向与危险预警 |

此表保留职能设计，具体敌方单位和数量由阶段/战役维护；旧“首章四职能”不成为县城内容上限或下限。军旗可夺取、失守或破坏，须与队伍状态关联；器械操作条件见[装备与器械](战斗、装备与伤害反馈.md#equipment)。

<a id="battlefield-feedback"></a>
## 5. 反馈与验证

阵型重组、压缩、松散、溃散通过队伍形态和动作体现；士气压力、动摇、崩溃、恢复通过旗帜、动作、图标、文字、声音和颜色组合体现。目标面板显示归属、状态、压力、路线和合法来源；可设为目标、护卫、攻击或撤退。默认显示关键异常，细节可展开。

验证玩家能否指出变化的直接来源，区分个人接触与组织协同、目标压力与最终控制、军心民心与战斗士气。核查同时到达事件、目标失效、未知信息和指挥失能时的行为，不以隐藏随机主导失败。完整数值范围、状态映射、随机规则、阈值和战场目标树细则待定。技术只引用[军事领域](../../architecture/03-Owner领域/02-领域Owner详细契约.md#military-domain)与[公共事实合同](../../architecture/02-公共契约/02-Command事件与Receipt.md#command-event-receipt)。
