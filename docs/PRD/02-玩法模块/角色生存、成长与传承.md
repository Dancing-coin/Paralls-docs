<a id="survival-body"></a>
## 1. 需求、身体与行动能力

身体状态分为需求压力、疲劳、疾病风险、伤势、有效能力和恢复速度，不能压成一个立即扣除的全局惩罚。资源可获得性与消费机会先改变需求和身体，再通过劳动、组织、军心与士气产生后果；缺盐不能在短期内直接秒杀角色。温度、劳作强度、疾病、年龄、饮食、作战和持续时间共同作用，具体数值待定。

| 行为或条件 | 成本和结果 | 玩家反馈及边界 |
|---|---|---|
| 获取/消费粮、水、盐及其他需求品 | 占用资源、消费机会与时间，满足需求后影响身体与恢复 | 区分可获得、已消费、身体改变；需求系统不能自行扣款或改产权 |
| 高强度劳动、行军或作战 | 疲劳、压力和疾病风险积累，有效能力与恢复改变 | 状态有持续时间和中间反馈，不能隐藏直到突然失能 |
| 休整、救治和照护 | 占用安全地点、人员、药材、队列、时间及其他资源 | 展示伤病、排队、治疗条件、资源使用和恢复；具体速度/限制待定 |
| 伤势、失能与行动中断 | 影响移动、履职、发令、劳动或战斗 | 明确导致中断的身体/资格/资源原因，继任和后续责任不静默取消 |

Survival 提出消费计划；库存、付款、使用权、生产、身体、状态与生命结果仍由各自合法领域承认。治疗交互与动画不能自行加血，治疗动画结束不代表药物消耗和伤势恢复都已完成。完整串联由[补给、消耗与伤病救治](../03-跨模块流程/补给、消耗与伤病救治.md#medical-flow)维护，技术约束引用[身体领域](../../architecture/03-Owner领域/02-领域Owner详细契约.md#body-domains)与[资源领域](../../architecture/03-Owner领域/02-领域Owner详细契约.md#resource-domains)。

<a id="body-social-consequences"></a>
## 2. 身体后果进入社会

| 对象 | 可观察后果，不能直接替代其个人判断 |
|---|---|
| 居民 | 劳动能力、纳粮纳税、搬运、修工事与募兵意愿变化 |
| 军队 | 疲劳、疾病、补给压力、士气与撤退意愿变化 |
| 商人 | 现金流、信用、风险偏好、囤积与改投选择 |
| 官府 | 配给、赈济、查禁、征用、腐败或妥协 |
| 世族 | 支持、索取、联络旧主或重新下注 |

“高官府邸有盐而普通人无盐”必须经过观察、传闻、解释和角色候选行动，再按领域权限落实。候选可为抗议、举报、拒运、哄抢、投靠、隐忍或借机敲诈；不能由司命直接扣“居民忠诚 20”。关系和情报正式规则见[社交模块](社交、关系与情报.md#information-knowledge)，候选干预见[司命与角色智能体](司命与角色智能体体验.md#siming-candidates)。

<a id="growth"></a>
## 3. 三条成长线与角色来源

| 成长线 | 内容 | 获取方向 |
|---|---|---|
| 个人能力 | 武艺、将略、统御、政略、交涉、工巧和身体状态 | 亲战、训练、治理、谈判、经营、长期任职及实际后果 |
| 组织能力 | 任职经验、制度、授权网络、预案、市场和行政能力 | 组织运作与责任承接 |
| 军队训练 | 队形、通信、纪律、补给、器械和继任熟练度 | 训练和组织投入；时间、资源和战损影响稳定性 |

三条线互相影响但不合并为单一等级，不以单纯购买经验代替经历。以下保留原案阶段方向；它们不是当前 Demo 排期、解锁门槛或已实现内容。各阶段预期游玩时间仍为空白待决，具体奖励与成长公式待定。

| 阶段 | 新能力 / 内容 | 奖励 | 新挑战 | 预期游玩时间 |
|---|---|---|---|---|
| 前期 | 角色行动、直属组织、命令、基础战场目标 | 即时反馈和可复盘的行动结果；长期成长奖励  | 通信、位置、阵型/士气和个人暴露 |  |
| 中期 | 预案编辑/版本、授权、继任、区域战役与资源网络 | 代理覆盖、组织能力、关系和资源选择 | 多线行动、补给和信息时效 |  |
| 后期 | 派系、经济战、政治、继承、历史分岔和更大规模组织 | 事实统治、路线选择、历史改变 | 多 Owner 约束、持续成本和承接风险 |  |

可支持玩家自建角色，也可采用预设角色；创建本身不自动授予领地、军队、身份或指挥权。起始能力、关系和权限须与世界事实一致。创建维度、可选背景、能力分配、初始身体/装备、身份组织关系、预设角色范围，以及与主线和继任的关系均待定。

<a id="failure-inheritance"></a>
## 4. 重大失败与长期承接

重大失败可导致受伤、被俘、失势、流亡或死亡。原总案还保留角色在认为复起无望时选择自杀、或被杀的长期方向；具体触发、呈现、内容分级和玩家操作未确定，不能由整理补成机制。

长期承接方向是死亡后转至最近的可承接角色：配偶、子女、义子、部曲头目或亲信；无可承接者时才结束势力或本局。完整终局、继承候选资格、距离/关系含义与选择方式仍需剧本规则确认。**当前县城守城 Demo 的死亡、投降、逃离失败按 Demo 正式规则执行，不能用长期继承方向改成继续胜利。**

| 可承接的结构性内容 | 不完整承接的个人内容 |
|---|---|
| 领地、组织名分、部分制度、公开资源、部分关系网络 | 个人威望、私人信任、军功、武艺、秘密、记忆、直属忠诚 |

继承人有结构资源，仍需重新建立个人影响和事实统治；“刘禅继位”只是说明例，不是指定剧情或数值模板。指挥失能不等于政治继承：即时指挥权轮替见[命令与轮替流程](../03-跨模块流程/命令传递、执行与指挥权轮替.md#succession-flow)，其权限/预案交接不能自动继承所有个人关系。

<a id="survival-validation"></a>
## 5. 目标、验证与待定

沙盒不强制只有“统一天下”：保全家族、受封州牧、拥立天子、建立新朝、控制中原、复仇、维持独立均为目标例。正式目标、通关、角色死亡/组织瓦解/关键承认丢失是否终局、撤退/僵持/割据/拥立结果由总纲与具体剧本确认。

战役持续至玩家主动结束、死亡后无可承接者或明确时代终点，以及到时代终点后结算结束/继续架空，均保留为原案建议；具体年代、触发与表现待定。失败反馈需列主要来源、发生与获知时间、损失、可恢复项、承接权限及继续选项，不默认无后果重置。

验证关注需求→身体→劳动/组织的中间证据，伤病与恢复是否可观察，三成长线是否各有用途，继承是否同时保留组织连续性和个人重建代价。初始属性、上下限、资源单位、训练/成长曲线、恢复条件、伤势数值、难度和存档继承规格仍待定。
