<a id="information-knowledge"></a>
## 1. 世界事实与人物所知

世界实际发生、组织收到、玩家获知及玩家推断分别记录。亲见、传闻、推断、未知须可区分；报告包含谁、何时、来源与可信度，不将未侦察敌军、私人意图或远场库存作为全知 UI。信息可能延迟、失真、过期、误传或被截；真正的错误推断应有来源及证据链。

组织指标提供概览，不代替个人秘密。私人利益、意图和态度由情报、相处、异常行为、密谈及事件证据逐步发现。公开承诺、私下意图、执行能力和对方理解分开；玩家自身也可能误判。暂停内不得新增信息暴露，完整时间规则归全局规则维护。

查询和界面使用[受限投影](../../architecture/02-公共契约/03-受限查询与投影.md#restricted-projections)，不直接读取后端真相生成情报。行动反馈可以承认“尚未获知结果”，不得将未知改成失败或伪造确定结论。

<a id="social-relations"></a>
## 2. 人物关系与社会行动

玩家以交谈、协商、接触、任命、授权、结盟、交易、求援、说服、招降、赎俘或保护等行动影响关系；结果由身份、权限、亲缘、记忆、利益、性格、声望、信任、能力和现场条件约束。人物可拒绝、拖延、讨价还价、改投或表面服从；分辨其可知理由与未知动机。

遵令、抗命、修改或拒绝命令分别产生任务、军纪、信任、声望、关系及后续权限后果，不能只以任务成功/失败表达。关系也不自动授予产权、政治承认或军队指挥权，相关事实由所属领域确认。

<a id="media-interface"></a>
## 3. 通信媒介与输入边界

语音、书信、手势、口令、旗语、传令、会议、沙盘和舆图共同承载观察、表达意图、传达与核查，不能默认为瞬时全域遥控。输入与反馈形式，以及道具、角色能力、识字、语言、视线和现场要求仍待定；未决定的语音识别不能写成已实现功能。

玩家可在许可范围内提交意图、选择对象/目标/预案及检查报告；媒介、路径、覆盖和授权决定能否到达。需要实体中继时，亲卫、传令兵或责任人承担运输与风险。接收、理解、接受、执行及结果获知分开，完整生命周期及异常只在[命令流程](../03-跨模块流程/命令传递、执行与指挥权轮替.md#command-lifecycle)维护。

拒绝与失效反馈指出具体原因，例如无权、不可达、资源不足、已过期、目标变化、无法理解或对方拒绝；说明是否可改派、重发、等待、协商或选择替代预案。正式界面、键位及无障碍表由全局交互文档维护。

<a id="espionage"></a>
## 4. 细作与信息战

细作是有身份、关系、暴露、任务、证据链和死亡风险的角色或组织行动，而非抽象百分比按钮。任务目录保留探查库存、观察现金流、伪造信物、散播传闻、接触商人、破坏运输、制造冲突、反间和确认敌方预案；五阶段大纲的收买、伪装、传假消息和破坏供应使用同一链条。

输出先进入记忆和情报投影；破坏、交易、冲突及关系变化仅在相应领域接纳后进入事实。细作角色经过 L1 感知、L2 理解、L3 规划、三重过滤器和 L4 执行意图；司命可给机会、压力及揭示条件，不能直接替其完成。被捕、误报、假情报保留可追溯错误推断，不作无来源随机惩罚。

通信覆盖、时延失真、可信度、暴露与反间计算，敌意感知的来源/范围/预警、伏击追捕误判及脱离，个人面板的注意力和身体成本仍待定。验证需能从一条报告追到来源与时刻，并区分玩家错误判断、递送失败、对方拒绝和世界事实。
