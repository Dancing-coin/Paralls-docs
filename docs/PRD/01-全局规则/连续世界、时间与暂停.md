# 连续世界、时间与暂停

> 文档版本：v1.0（专题重组版）  
> 更新日期：2026-10-30  
> 评审状态：连续世界、工作层切换与完整暂停沿用已定规则；倍率与扩展模式待决  
> 实现状态：玩家语义规范；实现、自动测试与运行证据以技术/执行文档为准

<a id="continuous-world"></a>
## 1. 一条世界时间线

战略代理、行军实体、近场战斗、市场、运输、角色需求、关系、通信与政治后果共享同一世界时钟、身份链和存档。经营统治、战役、战争与个人行动不是不同时间轴。玩家不关注某层，不意味着该层停转；已发生的损失、交易、授权与控制变化不能因退出面板或重载表现撤销。

世界事实的发生、角色获知和玩家看到可能相隔很久。报告抵达时应保留其所描述的发生时间与获知来源，不能把旧情报标为刚发生。玩家语义详见[信息可见性与认知边界](信息可见性与认知边界.md#three-times)，字段、身份与时间校验只由[时间、身份与控制权契约](../../architecture/02-公共契约/01-时间身份与控制权.md#time-identity-control)维护。

<a id="spatial-continuity"></a>
## 2. 空间、精度与行动连续性

远处使用低细节代理，接近玩家时可展开中场行为或近场人物/战斗实体；展开不重置时间、不复制人物、不新造过去事实。远场战斗仍使用同一核心规则的低精度表达，推进命令状态、军旗、阵型、士气、补给、撤退和指挥继任；不可以“未加载”表示组织停止或自动胜利。

玩家实际到达、随军同行并满足相应进入条件后，才能具身参与对应战场。远处信息由战报、斥候、传令与观察抵达，不能通过地图远程跳转身体或实时处理所有地区。显示已知地点和规划路线可以是工作层能力，不能因此获得超出角色权限和认知的干预能力。

城内、村落、道路、野战区、攻方营地、粮道与设施共享人口、库存、产权/占领、损伤和时间后果。离开某地后其生产、运输、消耗、疾病、代理与组织活动在各自规则内继续。近远场交接的唯一推进与事实权威详见[系统边界](../../architecture/01-系统边界/01-系统边界与权威写入.md#system-boundaries)，不由本篇另立技术合同。

<a id="layer-switching"></a>
## 3. 工作层与镜头切换

切换经营统治、战役、战争、个人关注、第一/第三/俯视镜头或地图，不暂停世界，也不自动传送角色、改变身份或发出新命令。打开 UI、参与会议、查看舆图与沙盘时，周围人物、其他战线和个人身体仍处于世界中，敌意、伏击、追捕与攻击仍可能打断交互。

未由玩家直接处理的职责交由已授权人员、预案、既有目标与继任关系继续。切换关注不撤销已发生结果，也不扩大代理权限。具体操控方式见[具身操作、骑乘与视角](../02-玩法模块/具身操作、骑乘与视角.md)，可操作范围见[身份与入口](玩家身份、权限与操作入口.md)。

<a id="active-pause"></a>
## 4. 单人主动暂停：完整世界时停

主动暂停与工作层/镜头切换是不同操作。单人主动暂停冻结世界时间和全部世界推进，包括：

- 角色移动、战斗推进、动画与物理；
- 命令与情报的传递、运输、生产、消费和其他按周期运行的活动；
- CharacterAgent、群体模拟与其他角色/组织推进；
- 领域提交、语义交接与新的认知/信息暴露。

暂停中可观察暂停前已经合法显示的信息、思考并编辑本地命令或预案草稿。草稿不等于正式下达、传达、接受或执行；暂停不能新增侦察报告、扩大视野、完成远处结算、推进信使、获取新的未知信息或免除行动成本。界面操作不得借暂停替世界继续工作。

恢复后才允许传达/提交草稿，并按恢复时的身份、权限、对象与世界状态重新校验。过期许可、目标变化、冲突和异步结果依公共契约拒绝、重校验或等待，不以暂停前的界面预览强制成立。精确冻结范围、恢复与版本/控制权规则只见[公共暂停契约](../../architecture/02-公共契约/01-时间身份与控制权.md#pause)及[运行时接入](../../architecture/05-运行时接入/01-UE本地提交与Paralls同步.md#ue-paralls)。

保存、暂停、恢复和断线是不同事件。保存/恢复应保持同一连续世界；Bridge 断开并不等于暂停，也不自动将远端权威转交 UE。已获准本地计划能否继续由许可与领域边界决定。

<a id="season-and-cadence"></a>
## 5. 周期、季节与速度

战斗接触与命令具有即时反馈，市场、运输与角色决策采用各自短周期，家庭消费和补给具有日尺度，税粮、征募、训练与政治承认具有旬/季等组织周期。这里说明玩家体验的不同节奏，**不是另一份 Owner 更新矩阵**；全量技术节奏只见[UE 节奏矩阵](../../architecture/05-运行时接入/01-UE本地提交与Paralls同步.md#ue-cadence-matrix)。

季节不是回合门槛。春耕、夏征、秋战、冬训组织年度行动节奏，但玩家可在任意季节行动，并承担粮秣、劳力、天气、道路和民心代价。时间倍率、加速条件、摘要频率、睡眠/等待的具体成本与恢复规则尚待定；不能从“实时持续”推导世界时间必须与真实秒数一比一。

单人完整暂停已确定。慢速/加速是原设计中的扩展方向，具体规则另行评审，不以慢速替代已确定的完整暂停。原总案对未来多人/合作提出取消真正暂停、保留慢速或房主有限暂停的候选；多人尚非当前交付，不在此定稿。

<a id="demo-time"></a>
## 6. 当前 Demo 与长期保存

当前召陵县守城 Demo 支持跨多个世界日保存、暂停与恢复，核心围城窗口约 30 个世界日；真实分钟数由倍率与试玩校准。历史骑将切片的 3–8 分钟不成为守城 Demo 时长要求。围城前后的人口、库存、设施、关系、伤病与战争状态应按当前范围保留，完整战后经营及进入第二阶段的开放方式仍待确认。

当前死亡、投降与逃离的失败规则不能被存档连续或完整游戏继承方向替换；具体条件由场景胜负配置维护，详细来源与摘要简写的差异见[待决 D08](../00-产品总纲/设计决策与待决问题.md#d08)。长线承接与终局未决见[世界扩展路线](../00-产品总纲/世界扩展路线.md#long-term-acceptance)。

<a id="time-validation"></a>
## 7. 规则验证与来源

验证应分别观察：工作层切换时世界继续；暂停时全部推进与新信息冻结；恢复草稿重新校验；近远场展开不复制身份和历史；跨日保存恢复后库存、伤势、授权与时间一致；远方报告保留发生/获知差异。此处列验证责任，不宣称测试已经通过。
