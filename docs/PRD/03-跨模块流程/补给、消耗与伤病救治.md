<a id="supply-flow"></a>
## 1. 从供给到可执行能力

`生产/掠夺/交易 → 仓储 → 装载与运输 → 粮道/商路 → 实际抵达 → 配给与消费 → 生命、健康、疲劳、军心、士气、战力 → 阵型、执行、伤亡、撤退及政治后果`

| 环节 | 校验与可见结果 | 异常及承接 |
|---|---|---|
| 需求与计划 | 角色/家庭/军队/工坊需要什么、何时需要；提出消费或采购计划 | 需求系统不自行扣款、扣库存或改变产权 |
| 筹集与预留 | 来源、数量质量、所有/使用权、预算及预留版本 | 被预留、藏匿或不可达库存不能作有效供应；缺口明确 |
| 分配与生产 | 配给政策、生产任务、劳力设备、成本和竞争用途 | 修缮、箭矢、医疗等竞争同一真实库存；不能重复消费 |
| 发运与抵达 | 承运人、路线、阶段位置、护送、交接及入库 | 阻路、改道、拦截、损失、放弃分别反馈；未到不算到货 |
| 消费与身体 | 确认消费机会、数量质量、身体状态及恢复 | 食物、水、盐、药不共享一个全局惩罚；缺口按具体条件持续影响 |
| 劳动与组织 | 可用劳力、纳粮、搬运、修工事、募兵、军队疲劳/疾病、坚持或撤退意愿 | 组织和人物依据可见证据响应，军心、战斗士气及民心分别结算 |
| 核查与调整 | 玩家收到来源、时刻、可信度与阶段报告 | 世界变化和玩家得知不同步；改变配给、改道、求援或降低目标仍须合法提交 |

盐战保留明确因果：盐源/运输受控→可购买量下降、涨价、排队/配给→部分家庭军队需求未满足→身体压力、疲劳及劳动能力变化→家庭生产、运输、纳粮、募兵和修工事能力下降→角色不公感、恐惧、投机、抗税、拒运、逃亡或继续服从→组织/军事领域确认后果。缺盐不短期自动判死，不直接扣“混乱度”；高温、重体力、疾病、年龄、饮食、作战和持续时长改变压力，长期严重缺口才可能造成严重身体后果。

ResourceBodyRuntime、Status Tags、Effective Stats 和 Survival Authority/计划中周期需求是原案提出的 Paralls 基础；完整盐代谢、群体生存到军事反馈属于增量方向，不宣称现有实现。详细库存、市场、产能和运输规则仅在[资源模块](../02-玩法模块/资源、生产、经济与运输.md#resource-network)维护；身体、社会响应在[生存模块](../02-玩法模块/角色生存、成长与传承.md#survival-body)维护。

<a id="medical-flow"></a>
## 2. 受伤、转运与救治

1. 接触、防护、伤害评估、身体应用、状态效果和生命周期依[战斗伤害链](../02-玩法模块/战斗、装备与伤害反馈.md#damage-chain)分别确认，不凭动画判死。
2. 识别伤势、失能、疲劳、疾病/中毒及可行动能力；可用医护、担架、路线、医疗场所与军纪/组织条件决定能否转运。
3. 排入医疗队列并预留药材、水、食物、劳力等适用资源；医疗和生产/防御竞争库存与工时，不能产生免费恢复。
4. 库存消费、身体治疗、状态创建/减轻/解除各自确认并给回执；药已使用不等于治疗成功，身体改善不等于疾病已解除。
5. 根据实际恢复、风险及岗位条件继续休养、转岗、返队或返家庭；保留身份、关系、技能、伤势记忆及经历，不能重置成新单位。
6. 失能、死亡、被俘、投降与逃离的控制及组织后果单独处理。当前县城 Demo 失败由阶段配置维护；长期传承不能覆盖当前失败条件。

补给/医疗被阻、污染、物资损坏、设施失控、医护不足、排队过长或治疗中断时应说明原因和剩余选择。粮水投毒、污染发现、隔离、救治与追查使用同一资源、身体、情报和组织链，不能只触发剧本扣血。

## 3. 验证与待定

需求具体量、身体耐受、时长、医疗顺序、配方和成功条件、伤残与复归阈值、污染模型、救治优先级和资源分配的政治代价待定。验证须能追溯一次未满足需求或伤势如何改变工作/命令/战斗，并包含一次阻断、延误或不公分配后的不同角色响应；不以库存减少即证明完整链条。
