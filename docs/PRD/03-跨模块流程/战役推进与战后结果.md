## 1. 持续世界中的决策循环

战争确定冲突目标、投入和收束方向；战役把它们落实为阶段目标、参战组织、预案、补给与行动；局部战斗形成接触、损失和控制事实。三者共享[连续世界与关注层](../01-全局规则/连续世界、时间与暂停.md#layer-switching)，打开/关闭面板不新建独立回合或移动角色。

| 关注层 | 通用操作流程 | 主要约束及反馈 |
|---|---|---|
| 经营统治 | 在势力范围或有效通信覆盖内打开治理入口，或在府署/营地/会议交互→读取观察/已到报告→设政策预算目标→任命/授权→持续运行→根据异常核查→调整 | 离开覆盖后须经可用媒介继续传达；政策颗粒度、核查频率、代理失败细则待定 |
| 战争/战役 | 有权限、地图/战报及媒介→在面板或沙盘/舆图与将领推演→斥候报告更新判断→确定目标、投入、预案和补给→传达→敌我与中继持续执行→新情报后调整或亲自介入 | 其他战区、后勤和政治继续；地图尺度、时倍率、排程及目标收束待定 |
| 个人行动/战斗 | 读取身份位置身体关系与可知信息→移动/骑乘/交互/交涉/调查/履职/休整/社交/亲密互动→主动或被敌意触发接触→现场校验→即时操作反馈→身体位置关系战场及时间后果 | 治理/战役关注期间身体仍在原位；人物与敌意可打断沙盘等交互；失能撤退死亡后控制见相应模块 |

玩家可以观察合法情报→暂停核对资源、组织与可达性→发求援/守备等意图→恢复后观察传令、运输、生产及敌情→核查/追补/亲自介入→承受后果。暂停完整边界只在[全局暂停](../01-全局规则/连续世界、时间与暂停.md#active-pause)维护。亲自出城可扩大局部影响，也会降低对城内事务的指挥可达性；不能同时获得所有位置收益。

<a id="mission-template"></a>
## 3. 战役与任务内容模板

每项内容必须登记目标来源、参与组织、可用情报、玩家可亲自执行/委派的行动、资源和权限要求、失败/撤退条件、结算事实及持久后果。正式主线章节、支线、动态事件、战役类型、势力内容量、解锁顺序与首个正式任务仍待定；不能填造为空白位置的产品决定。

长期节奏须同时考虑战斗、治理、外交、组织维护、角色发展及世界事件，阶段变化与促使玩家返回关键行动的触发方式未定。短时局部目标的可读性，不等于给所有战役固定 `3–8 分钟`；旧切片时长的失效状态由[决策登记](../00-产品总纲/设计决策与待决问题.md#d05)维护。

<a id="war-results"></a>
## 4. 战斗结束与持久后果

1. 接触、目标压力、控制、损毁、伤亡、失能、俘虏、撤退和补给分别来自相应事实；[目标失效](../02-玩法模块/士气、阵型与战场目标.md#objectives)须通知相关组织重评，不静默判整场结束。
2. 命令、预案、训练、士气、阵型、地形及接触影响组织执行；失联、拒绝、指挥失能按[命令与继任流程](命令传递、执行与指挥权轮替.md#succession-flow)承接，离场不停止也不脚本自动胜利。
3. 损失、控制、俘虏、资源消耗与收益回写战役/战争及治理；个人伤势、关系、记忆、职责与许可持续影响后续行动。一次亲战成果不能跳过其他组织、政治承认或资源领域。
4. 占领后追击、收容、治安、损毁、税粮运输及关键人物配合进入[统治过程](../02-玩法模块/治理、政治与领土控制.md#territory-control)，军事占领不等于稳定统治或全部产权取得。
5. 世界先形成结果，玩家经观察或报告获知；确认、执行状态、结果回执和信息抵达分层呈现。战报需说明谁、何时、来源、可信度、变化及后续可选行动。

当前只有县城守城 Demo 是开发与验收目标，具体角色、命令、约三十日窗口和死亡/投降/逃离失败维护于[召陵县目标配置](../04-内容与剧本/召陵县/目标、事件与胜负配置.md)。完整游戏目标、通关、最终失败、结局结构和长期继承边界仍待定，长期角色传承不覆盖当前 Demo 失败。

## 5. 可复盘标准与待定

可用规则表/小规模模拟、命令路由测试、Bridge 关闭测试、PIE 观察、跨战役对照和长线试玩验证，方法不等于已执行。检查玩家能否理解关键变化来源，个人行动与组织协同是否各有用途，命令是否因延迟无意义、职责是否可辨、离场自治是否真实、隐藏随机或经济政治单值是否支配结果。具体样本、周期、指标、地图与任务规模仍待定；若核心闭环失败，先调反馈、目标差异、通信、预案和接触风险，缩小内容而非增加单位。
