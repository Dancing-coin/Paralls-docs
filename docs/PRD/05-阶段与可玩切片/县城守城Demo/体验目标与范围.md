## 当前目标

当前独立开发和验收目标统一为县城守城 Demo；骑将冲阵只作为历史方案和可吸收机制来源。玩家在有限身份权限、合法已知情报和连续世界约束下完成“军情—求援—守城—胜负”。骑乘、视角、传令、士气、阵型与目标仅按本 Demo 需要接入。

三队配置在县城旧设计和角色需求中另有独立来源，暂列待决；`10/22/34` 不设为当前强制命令映射，3–8 分钟冲阵不作为当前验收时长。参见[设计决策与待决问题](../../00-产品总纲/设计决策与待决问题.md)。

## 2. 目标、非目标与反目标

### 2.1 目标

1. 做出一段可连续游玩的县城守城 Demo，至少支持一次完整的“军情—求援—守城—胜负”流程。
2. 建立可延续到后续阶段的世界时间、三本账、Command、Owner、EventStore、revision、幂等、receipt、replay、projection 和 recovery 基础。
3. 让玩家能在有限信息和有限权限下，通过传令、组织、资源和个人行动影响战局。
4. 让角色智能体、群体模拟和 UE 表现使用同一套事实链，且能在近场和远场之间切换而不重置身份或事实。
5. 让每一次胜利、失败、拒绝、延迟、阻挡、拦截和部分完成都可以通过日志和战后摘要复盘。

### 2.2 非目标

- 全国地图、多郡多县、多人联机和联网服务。
- 全量居民使用 LLM；普通居民只需要 B0/B1 低精度推进。
- 完整市场经济、复杂税制、完整政治制度和所有历史剧本的第一阶段内容；相关 Owner 的通用结算、事件和恢复能力仍属于基础设施范围。
- 所有攻城器械、火攻、水攻、地道和完整攻城工程链。
- 大规模高模角色、最终美术、完整配音和复杂 UI 皮肤。
- 让动画、Actor 字段或 GameMode 成为第二套世界真相。

### 2.3 反目标

以下任一情况都视为架构失败，即使画面能播放：

- 打开面板或切换镜头就直接改变远方事实；
- 角色 Agent、群体模拟或 UE 表现层直接写库存、位置、伤害、士气或胜负；
- 事件只能从当前 Actor 状态猜回，不能从事件流重建；
- Bridge 断线时 UE 和 Paralls 各自产生一套互相冲突的结果；
- 玩家不知道命令为什么失败，也无法区分“已下令”和“已执行”；
- 暂停后仍有运输、生产、动画、Agent 或异步回调推进世界；
- 玩家只靠反复单骑冲锋就能稳定解决守城问题。

## 正式基础与内容范围

县城、村落、攻方营地、粮道和角色按同一世界时钟运行；约30世界日的援军与提前逼退敌军的具体条件由[剧本配置](../../04-内容与剧本/召陵县/目标、事件与胜负配置.md)唯一维护。出城反击、粮道截击、运输护送、夜袭、破坏器械、招降和秘密运输均为可行策略而非强制任务；全程闭城守备也可胜利。

“最小”只限制第一阶段内容规模，不缩减正式基础设施语义、Owner合同或事实治理。第一阶段建立五阶段可复用的基础能力；后续扩充内容、规则与跨域流程，不能另起第二套事实系统。全领域完成口径引用[注册表与完整交付包](../../../architecture/03-Owner领域/01-Owner注册表.md)、[WRK与三本账](../../../architecture/01-系统边界/03-三本账与WRK.md)和[存档回放恢复](../../../architecture/06-存档与可观测性/01-存档回放与故障恢复.md)，能力阶段门见[建设计划](../../../production/基础设施与Owner建设总计划.md)。不得把“先做守城闭环”解释为只做临时最小Owner；也不得把全国fixture等同全国内容已制作。

每个可见结果必须能追溯提出的意图、命令实际传达、获准Owner承认的事实、角色/玩家获知和UE表现时点，具体契约不在范围文档重复定义。

## 4. 核心体验循环

### 4.1 玩家循环

```text
观察合法可知情报
  -> 暂停、检查资源/组织/命令可达性
  -> 发出求援和守城 Command
  -> 恢复世界，观察传令、运输、生产和敌军反应
  -> 追问、核查、追加命令或亲自介入
  -> 承担伤亡、短缺、失误和政治后果
  -> 直到援军抵达、敌军撤退、县城失守或玩家失败
```

### 4.2 必须体现的取舍

- 亲自出城会提高局部战斗影响，但会降低对城内命令和传令的可达性；
- 集中资源修城、生产箭矢或救治伤员，会减少其他用途的库存；
- 命令可以发出，但传令可能被阻挡、误解、延迟、截获或过期；
- 角色有服从义务，但可因失效条件、能力、恐惧、疲劳、家庭责任或自身判断拒绝、拖延或改写执行方式；
- 暂停只给玩家思考和下达命令的机会，不会刷新未知情报或完成异步事务。


## 规则与配置入口

- 暂停、信息和权限见全局规则；完整时停中只能编辑命令草稿，恢复后才传达。
- 场景、角色、初始资源、时间与胜负由[场景布局](../../04-内容与剧本/召陵县/场景布局与功能分区.md)、[目标、事件与胜负配置](../../04-内容与剧本/召陵县/目标、事件与胜负配置.md)及[角色、势力与初始状态](../../04-内容与剧本/召陵县/角色、势力与初始状态.md)维护。
