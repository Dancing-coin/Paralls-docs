## 使用说明

本模板用于整理一款游戏的总体设计。按项目规模增删章节：独立游戏可将本文作为总案，较大型项目可将玩法、系统、关卡、角色等内容拆分成子文档，并在相应章节填写文档链接。方括号内是填写提示，完成后可删除。

先讲清游戏是什么、玩家反复做什么、如何判断成功，再逐步细化系统规则和制作内容。未决定的信息标为“待定”，设计假设与实测结论分开记录；避免为填满章节而增加并非必要的功能。
