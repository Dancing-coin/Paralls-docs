## 1. 使用方法

本文件包含四个视角，每个视角三张图，共 12 张。每条提示词都应与“统一视觉前缀”“统一 UI 布局”和“全局负面提示词”拼接使用。建议统一使用 `1536x1024`、16:9 横构图、`medium` 或 `high` 质量，并将前一张图作为角色、军旗、场景和 UI 连续性参考。

四个视角共享同一场战争事实、同一玩家角色和同一套情报状态。相机切换不能改变玩家位置、朝向、速度、伤势、命令状态、通信延迟、已知情报或世界时间。

### 3.1 视角专用相机定义

```text
第一人称：真实眼高，近距离身体遮挡，真实双手和武器进入画面，不显示完整玩家脸部。
第三人称：玩家后方或侧后方 2.5–4 米的跟随相机，显示玩家身体、坐骑、武器动作和亲卫关系，不是英雄海报构图。

```

### 3.2 情报与通信的统一视觉规则

```text
直接观察：正常材质、清晰动作；实时通信：低透明度动态轮廓；新鲜战报：半透明单位虚影并标出最后已知时间；过期情报：淡化轮廓和方向痕迹；未知区域：自然雾区，只保留已知地形轮廓。情报虚影不能伪装成实时单位。通信网络用暗红、灰白、低饱和青绿的细线、节点和地面淡色边界表达，不使用科幻雷达圆圈。镜头移动不扩大通信覆盖，摄像机看到的区域不等于玩家知道的区域。
```
