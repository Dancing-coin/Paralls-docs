- 全县城统一 WRK；

- 完整居民、家庭、岗位、日程和影响力模型；

- 三本账的全量同步合同与 `event_time/known_time/presented_time` 统一回放；
- 最终单一路径 `L4 -> UE Character Actor`。

## Guoshang 2026-10-28 代码盘点

### Guoshang 当前实现盘点

### 已有但不等于 Owner

`AStrategyUnit` 已有 AIController、EQS、NavMesh 移动、到达委托和 Blueprint 交互回调。它的调用链是：

```text
MoveToLocation
→ EQS
→ AIController::MoveTo
→ OnMoveFinished
→ Blueprint interaction
```

这可以继续作为 UE 局部执行器，但没有命令、权限、revision、receipt、事件账、暂停屏障、回放和恢复，因此不能直接承担 Presence Owner。

`ABattleUnit` 当前把 `UnitId`、`ArmyId`、`FormationSlot`、`Morale`、`TrainingLevel` 和 `bCombatCapable` 放在 Actor 的普通属性中。它们分别属于身份、组织/阵型、士气、训练和身体/战斗领域，未来应改为 Owner 投影字段。

`ABattleRiderCharacter`、`ABattlePlayerController` 和 `BattleViewMode` 已提供骑将移动、冲锋、第一/第三/俯视视角和输入基础。这些是应该保留的传统 UE 能力，但玩家输入造成的世界事实必须经由 Command、Presence 或 Combat Owner 确认。

`BattleGameMode` 和 HUD 当前只设置 Pawn、Controller、HUD，并显示视角与操作提示，还不是县城世界运行时。

### 当前缺口

- 没有统一 World Time、暂停屏障和 WRK。
- 没有县城级 Command/Dispatch 和传令反馈。
- 没有 Military Organization、继任和预案事实。
- 没有 Morale/Formation、Combat/Damage、Objective/Victory Owner。
- 没有 Presence/Movement 的事实提交边界。
- 没有资源库存、运输、生产和政令的 Owner 接口。
- 没有 UE 与 Paralls 的统一 projection、handoff、receipt 和 replay 接入。

## Owner 与当前 Paralls 实现的关系

### 与 Paralls 当前实现的关系

Paralls 已有 GameplayEventStore 与多类领域 authority、Owner fragments、revision/CAS、幂等、receipt、outbox、checkpoint 和 replay。这些是 Guoshang 可复用的实现基础，不代表 Guoshang 领域已经完成。

| Guoshang 目标 | Paralls 对照 | 判断 |
| --- | --- | --- |
| 结算基础设施 | `GameplayEventStore`、`AtomicEventBatch`、receipt、outbox、replay | 可复用语义；不建第二套事实账 |
| 基础 Owner | ownership、spatial、capability、identity 等局部能力；全域时间/空间仍有缺口 | 逐项核验事实覆盖，不能宣称完整基础层 |
| 原子 Owner | inventory、equipment、resource/body、status、ability 等窄纵切 | 复用合同和实现模式；逐项核验事件、revision、回放与业务覆盖 |
| 组合过程参考 | survival、construction/production 模块内的跨域流程片段 | 只复用过程合同；模块内真实领域写权分别保留给 Survival、Production 等 Owner，不将整个模块误归为无写权 Workflow |
| 协调能力 | caller-driven 调度、population cadence、部分 obligation/recovery | 不等于完整 WRK 或通用 Workflow 引擎 |

`resource_body_runtime.py` 把资源与身体代码放在同一模块，不代表角色身体指标和世界物资属于同一本账或同一 Owner。角色携带的刀、粮食、药品仍是物资事实，由 Inventory/Ownership 管；生命、体力、伤势由 Body 管，饥饿/饱腹、口渴和疲劳由 Survival 管。
