# 汝南郡三十七城县治考证稿

名册完整覆盖《后汉书·郡国志》的三十七城（县级单位含县与国）；其中三十二处按 CHGIS 记录落点，五处尚无充分证据定位。此稿不构成三十七处治所全部定位的历史复原地图，也不复原郡界、县界、道路或古河道。现代经纬度为研究网格，不是古代地图原貌。

采用东汉顺帝时期《郡国志》名册口径，不声称等同某个汉末年份。西华等存在名册归属与数据库年代断面的差异。下一版须选定考订体系并核对县级详细历史地图后再解决这些差异，不能把后世同名县或现代县城直接代入。

未取得可核验的、覆盖三十七城的县级汝南郡参考地图，不能声称已经参照《中国历史地图集》详细县图临摹。全国参考图不足以解决五处缺口。

## 数据例外

- 㶏强 hvd_83019：数据库时间字段只覆盖25—29年的侯国，源注另明确记同址县30—265；本稿据源注保留落点，县/侯国属性沿革仍有差异。
- 鲖阳 hvd_83098：begin字段为206，但源注明确记公元前206年置县、东汉因之；据源注处理该符号错误。
- 平舆 hvd_83172：采用射桥镇古城村的历史治所，不是现代平舆县城；不把东晋后悬瓠郡治倒置到东汉。
- CHGIS记录可能有本身错误；本图中的点是数据库复原点位，五位小数不等于遗址测绘精度。

## 生成、核验与用途

初版 v001 曾用 gemini-3-pro-image-preview 测试生图，保留于旧版目录；它的五县示意不能作为史实底图。v002 用 Pillow 按资料坐标绘制，未再次调用付费生图模型；县名与点位不会由生图模型自行改写。

运行本目录 `build_map.py` 可重建 PNG、预览、JSON、CSV 和验证报告。程序检查37个唯一名目、32个坐标、5个缺口及标签包围框无重叠；已实际查看输出预览。分辨率4200×3000。未启动UE、未导入资产，无关卡或Actor变更。旧版完整保留。
