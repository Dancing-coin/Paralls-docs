# 阶段一战场概念摆放蓝图

参考图：`concept_battlefield.png`

## 空间关系

- **玩家起点**：西南侧低坡，骑将与两名亲卫在同一安全起步区。
- **己方两队**：西侧偏南/偏北的两块蓝色队列，面向中央。
- **中央目标**：地图中心的石质目标台与军旗，玩家靠近并持续占领。
- **敌方两队**：东侧偏南/偏北的两块红色队列，面向中央。
- **敌将**：东侧后方高地/营门前，作为明显红色垂直地标。
- **道路**：从西南玩家区汇入中央，再分叉到敌方两队与敌营。
- **掩体与地编**：外围放置少量岩石、树木和木栅栏；中央冲锋通道保持开阔。
- **后撤线**：南侧和北侧外围各一条短木桩线，作为双方撤退方向提示。

## 关卡读图约束

1. 俯视镜头必须同时读到两侧阵地、中央目标和至少一条道路。
2. 蓝/红只用于阵营与军旗，地面保持低饱和绿/土色。
3. 中央目标周围留出骑将绕行空间，避免被树木或掩体堵死。
4. 第一轮场景只使用少量静态网格，不追求数量；队伍行为和命令传递优先。
