# 05-传播延迟与失真模型

- 版本：1.0
- 状态：已定义
- 上级：[架构入口](../README.md)
- 前置：[可见性强制](02-可见性强制.md)

`02-可见性强制` 定义了 `delay` 与 `distortion` 两个字段存在，但没有给出它们的规格。本文件补齐。

**这是本项目的体验内核**：玩家作为县城统治者，依据迟到的、可能失真的军情做决定。

---

<a id="why"></a>

## 一、为什么这两个模型必须是 Resolver

延迟取决于距离、渠道、天气、道路、是否封锁；失真取决于渠道、来源可信度、传播长度。

这些都是**规则**，不是常数。但它们又必须：

- 可版本化（换设定时换参数）
- 可回放（同一输入同一输出）
- 双端等价（C++ 与 Python 结果相同）

因此它们是 L4 的 Resolver，不是规则包里的数据表，也不是代码里的 if/else。

<a id="delay-model"></a>

## 二、延迟模型

### 输入

```text
delay_input:
  fact_type_ref        ref
  source_owner_ref     ref
  event_time           int
  origin_ref           ref          事实发生地
  observer_ref         ref          观察者
  channel              enum(direct|report|rumor|inference)
  params               map          规则包提供的参数

  # 由 L0 固定 revision 的只读输入，缺失则不评估
  distance             dec?         起点到观察者的距离
  road_condition       enum?        道路通行状况
  weather              enum?        天气
  comm_blocked         bool?        通信是否被封锁
  carrier_speed        dec?         传令速度（若经信使）
  literacy             bool?        观察者能否阅读（若经文书）
```

### 输出

```text
delay_result:
  status            enum(resolved | unknown | rejected)
  delay_ticks       int ≥ 0          known_time = event_time + delay_ticks
  confidence        enum(full | degraded)
  basis_refs        list<ref>        支撑该结论的输入引用
  reason_code       enum?            rejected / unknown 时
```

### 通道基线

| channel | 默认延迟来源 | 典型量级 |
|---|---|---|
| `direct` | 0（亲眼所见） | 0 |
| `report` | 距离 / 信使速度 / 是否被截 | 分钟到小时 |
| `rumor` | 社会网络传播 | 小时到日 |
| `inference` | 由已知事实推算 | 取决于推理链 |
| `none` | 不可知 | ∞（不产生 known_time） |

### 硬约束

| 约束 | 拒绝码 |
|---|---|
| `delay_ticks < 0` | `delay_negative` |
| `channel=direct` 但 `delay_ticks > 0` | `delay_direct_must_be_zero` |
| `channel=none` 却返回 `known_time` | `delay_none_produced_time` |
| `distance` 缺失且模型需要它 | 返回 `unknown`，不默认 0 |
| 输入 revision 过期 | 返回 `unknown`，标 `input_stale` |

**最后两条是关键**：距离未知时默认 0 延迟会让远方军情瞬间到达，这是最坏的一种错误。

### unknown 的语义

`unknown` 时该事实对观察者**视为不可知**，而不是"延迟为 0 或无穷"。

这是有意的：系统不知道，就不能假装知道。玩家看到的是"我还不知道"，而不是"敌人已经打过来了"。

<a id="distortion-model"></a>

## 三、失真模型

### 输入

```text
distortion_input:
  fact_type_ref        ref
  source_event_ref     ref          原始事实
  channel              enum
  hop_count            int ≥ 0      传播跳数
  source_credibility   enum(high|medium|low)?
  params               map
```

### 输出

```text
distortion_result:
  status            enum(resolved | none | unknown)
  distorted_payload map?            失真后的表述
  distortion_kind   enum(magnitude_error | source_error | time_error | content_loss | fabricated)?
  observable        bool            接受者能否察觉这是失真的
  source_event_ref  ref             始终指向原事实
  reason_code       enum?
```

### 五种失真

| kind | 语义 | 例 |
|---|---|---|
| `magnitude_error` | 数值偏差 | 三千人被报成五千 |
| `source_error` | 来源错误 | 敌情被说成己方侦察 |
| `time_error` | 时间偏差 | 昨日之事报成今日 |
| `content_loss` | 内容缺失 | 报告只说"有敌"，不说数量 |
| `fabricated` | 完全捏造 | 伪造的军情 |

### 硬约束

| 约束 | 说明 |
|---|---|
| 失真不改变 `fact_type_ref` | 仍是一条同类事实 |
| 失真结果必须携带 `source_event_ref` | 可追溯原事实 |
| `channel=direct` 不产生失真 | 亲眼所见不扭曲 |
| `hop_count=0` 不产生失真 | 直接来源 |
| 失真不得修改原事件 | 原事实不可变 |

### 可察觉性

`observable` 决定接受者能否判断"这条信息有问题"：

- `observable: true` → 角色可据此选择核实
- `observable: false` → 角色只能按失真的信息行动

**这是玩法差异的来源**：同一份假军情，有人会怀疑，有人会中计。

但注意：`observable` 只是**能否察觉**，不决定**是否察觉**。是否起疑属于角色心智（`agent_private`），不属于世界真相。

<a id="chain"></a>

## 四、传播链

一次事实传播可以经过多跳：

```
事实发生
  → 甲亲眼所见（direct, delay=0）
  → 甲报给乙（report, delay=5, distortion applied）
  → 乙传给丙（rumor, delay=20, distortion applied again）
```

### 规约

| 项 | 规则 |
|---|---|
| 延迟累加 | 每一跳的 delay 相加 |
| 失真累积 | 每一跳的失真作用于上一跳的结果 |
| 原事实引用 | 始终指向最初的 `source_event_ref` |
| 跳数上限 | 32（超出视为不可知，防爆炸） |

### 与三本账的关系

每一跳产生的是**传播事件**（世界真相：谁向谁报告了什么），不是新的事实。

角色最终形成的**信念**写入其记忆账，可以是失真的。世界真相始终只有一条原事实。

<a id="authority"></a>

## 五、模型归属

| 模型 | 归属 | 理由 |
|---|---|---|
| `delay` | Information / Intelligence Owner | 传播是情报域的事实 |
| `distortion` | Information / Intelligence Owner | 同上 |
| `readability`（能否阅读） | Population / Work | 识字属于人口事实 |
| `road_condition` | 环境事实（待定归属） | 见待决 |

**延迟与失真模型归 Information Owner**，因为"传播"是情报域的核心事实。但它们**读取**其它域的只读投影，不写。

<a id="cross-host"></a>

## 六、双端等价

延迟与失真是纯函数，必须满足 [事件 schema 规格](../02-原语/04-事件schema规格.md) §七 的全部要求：

| 要求 | 说明 |
|---|---|
| 无浮点 | 用 `dec` 定点 |
| 无随机（除非固定 seed） | seed 来自 `world_tick` 或 `command_id` |
| 遍历顺序确定 | 来自注册表，不来自容器 |
| 无时间依赖 | 只看输入 |

### 固定向量

每个模型至少提供 20 组固定向量，覆盖：

- 各通道的基线
- 缺失输入的 unknown
- 多跳传播的累加
- 每种失真类型
- 边界（跳数上限、距离极值）
