## 一、世界时间

### 唯一时钟源

`world_tick` 只有一个来源：当前部署中的战场时钟。它是单调递增整数，暂停时保持不变。

### 部署前提（v1 未写明的假设）

v1 同时要求两件事：

- "`world_tick` 只能来自 UE 战场时钟"
- "WRK 拥有唯一 `world_tick`"

二者只有在**战场时钟与 WRK 同进程**时才相容。本设计把这个前提显式登记：

```text
前提 P-1：第一阶段为单机单进程部署。
          UE 战场时钟即 WRK 时钟，二者是同一对象。
          若未来拆为多进程，必须先建立时钟代理合同，
          并重新评估暂停屏障的跨进程覆盖范围。
```

未显式撤销 P-1 前，任何"后端起算时间"的实现都视为架构违规。

### 时间字段

每条事件至少携带：

```text
event_time        事实发生的世界时间
known_time        该事实对某一观察者可知的时间（按 visibility 计算）
presented_time    该事实被某一表现层呈现的时间
```

**当前实现状态（2026-11-10）**：角色记忆的生产装配已使用候选所属世界的已确认 Population 时间判断是否可物化；这是局部保护，不是通用的按主体计算 `known_time`，也没有完成 `presented_time` 与三时间统一回放。旧候选缺少世界来源时暂缓物化，已写入的历史记忆不会自动撤回。代码证据和限制见代码仓库 `docs/verification/g2-memory-world-time.md`，阶段状态见 [G1 与 G2 状态](../09-验收/G1-status-2026-11-10.md)。

三个时间不可互相替代：

- `event_time` 相同、`known_time` 不同 → 同一场战斗，不同角色在不同时刻得知
- `known_time` 相同、`presented_time` 不同 → 同一消息，UI 与动画错峰呈现

### 时间窗口与切窗

连续量的积分按窗口进行，窗口在下列边界结束并结清：

| 边界 | 说明 |
|---|---|
| 输入变化 | 治疗、负重、疲劳、温度等任一输入 revision 改变 |
| 阈值跨越 | 阈值或滞回边界被跨越 |
| 暂停 | 暂停屏障生效 |
| 交接 | 近远场切换、authority_epoch 变更 |
| 转仓/设施状态变化 | 容器或设施归属改变 |
| 绑定启停 | Applicability Binding 进入/退出有效窗口 |
| 版本升级 | 模型或规则包版本切换 |

**同一窗口不得重复积分。** 新旧推进者不能同时推进同一事实流。

## 二、暂停

暂停是**完整时停**，不是降频。

| 项 | 暂停时行为 |
|---|---|
| 世界推进 | 停止 |
| 效果 tick | 停止 |
| Timer / 异步回调 | 隔离，不触发玩法 |
| 网络返回 | 可以到达，但只入站缓存 |
| 记忆暴露 | 停止 |
| 表现推进 | 停止（可保留已确认尾动画，标 `presentation_tail`） |
| 玩家操作 | 只能编辑草稿，不产生新事实 |

### 恢复

恢复时必须校验三项，任一不成立则进入恢复流程而非直接继续：

1. `authority_epoch` 未变；
2. 读集 revision 仍有效；
3. 证据未过期。

**暂停与保存、断线是三件不同的事**，不能互相替代：

- 暂停：时间停止，会话继续
- 保存：状态落盘，时间可能继续
- 断线：时间可能继续，本地失去同步

## 三、身份

### 稳定 ID

实体身份是 L0 的基础事实，由 Identity 注册表维护：

```text
character_id / unit_id / group_id / facility_id / lot_id / region_id
```

规则：

- ID 一旦分配不重用、不回收。
- 显示名、编号、称号是投影，不是身份。
- 表现层（Actor GUID、实例 ID）只是引用，不是身份。

### 身份不随规模与宿主改变

```
char:county:guard-07
  ├─ Morale@角色        scope = self
  ├─ 属于 group:county:gate-east-squad
  └─ 在 B1/P0 或 B3/P3 表现下都是同一个 character_id
```

近远场切换、认知升降级、宿主迁移都不改变 `character_id`。

### 身份与连续性

跨系统的连续性记录至少包含：

```text
character_id
identity_revision
world_tick
cognitive_fidelity / presentation_fidelity
presence_revision / body_revision / command_revision / action_revision
embodiment_lease / intent_lease
last_handoff_id / last_receipt_id
knowledge_cut
```

`knowledge_cut` 表示角色实际可用的信息截止点。**不得因表现层发送了全局快照而让角色获得全知。**
